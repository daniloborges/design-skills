Nova skill `configurar-figma-console`: instala, diagnostica e ensina a usar a ligação do Claude Code com o Figma Desktop pelo figma-console MCP. A instalação padrão dispensa o token do Figma, porque o plugin Desktop Bridge cobre o trabalho no arquivo aberto; o modo `token` liga comentários, histórico de versões e biblioteca publicada quando a pessoa precisa.
